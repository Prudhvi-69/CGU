mvn : it is a command of maven which is used to run spring-boot application. 
** Inorder to use this we need to install the maven from internet manually.
** After installation we have to setup the system variable and its path.
** Then we can use mvn command anywhere in the system.
Ex : mvn spring-boot:run

mvnw : It is a command provided by spring boot wherer it is going to be used only at the project level but not at system level.
** to use this one we dont need any extra installations or downloads.
** Ex: ./mvnw spring-boot:run
