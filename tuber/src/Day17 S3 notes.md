React Router DOM : It is a tool which provides us the tags,elements and hooks which will let us use them for easy and better navigation than basic HTML navigation.

<BrowserRouter> : This tag will the browser know, React is going to take control of the content inside.

<Routes> : It is like a container, which holds multiple individual routes and their web url paths together.

<Route> : Each individual route and their web url path can assigned using Route tag.

<Link> : It is going to create a url path for a text in the webpage.
